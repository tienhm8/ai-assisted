# CODING RULES

1. Use TypeScript strict mode.
2. Follow project naming conventions.
3. Avoid any unless explicitly justified.
4. Use reusable components.
5. Avoid duplicated business logic.
6. Handle errors explicitly.
7. Validate input at system boundaries.
8. Do not hardcode secrets.
9. Write readable and maintainable code.
10. Remove unused imports and dead code.
